# Инструкция для специалиста по Тильде: два лендинга CleanHub на поддоменах

Задача: вывести два рекламных лендинга на отдельные поддомены, **не на основном сайте** cleanhub24.ru.

| Лендинг | Поддомен (пример) | Файл с кодом | Что внутри |
|---|---|---|---|
| Генеральная уборка | `general.cleanhub24.ru` | `generalnaya-uborka.html` | один блок T123 (HTML), весь лендинг |
| Уборка после ремонта | `remont.cleanhub24.ru` | `uborka-posle-remonta.html` | один блок T123 (HTML), весь лендинг |
| Страница «Спасибо» (в каждом проекте своя) | `…/spasibo` | `spasibo.html` | один блок T123 |

Каждый лендинг это **одна страница Тильды из одного блока T123 и попапа с формой**. Меню, шапку и подвал Тильды добавлять не нужно, всё уже внутри кода. Калькулятор, галереи, FAQ и скрипты работают сами, внешних библиотек нет.

> Названия поддоменов можно выбрать другие (например `uborka.`, `remont.`). Дальше в инструкции они указаны как `general.cleanhub24.ru` и `remont.cleanhub24.ru`.

---

## 0. Что нужно до начала

1. Доступ к аккаунту Тильды, где лежит основной сайт (чтобы скопировать из него настройки CRM и счётчиков).
2. Доступ к DNS домена `cleanhub24.ru` (у регистратора или в панели хостинга DNS), чтобы добавить записи CNAME.
3. Тариф Тильды, на котором доступно подключение своего домена (Personal или Business). **К одному проекту Тильды подключается один домен**, поэтому для двух поддоменов нужно **два проекта** (шаг 1).
4. Три файла с кодом (приложены).
5. Доступ к Яндекс.Метрике (счётчик `108429981`) и личному кабинету коллтрекинга i-media, если он используется.

---

## 1. Создать проекты и подключить поддомены

Для каждого лендинга делаем свой проект.

1. Тильда → «Мои сайты» → «Создать новый сайт». Названия: «CleanHub · Генеральная (реклама)» и «CleanHub · После ремонта (реклама)».
2. В проекте: **Настройки сайта → Домен → «Подключить свой домен»**, ввести `general.cleanhub24.ru` (во втором проекте `remont.cleanhub24.ru`).
3. В DNS домена `cleanhub24.ru` добавить запись:
   - Тип: **CNAME**
   - Имя (хост): `general` (для второго `remont`)
   - Значение: `cname.tilda.ws` (точное значение Тильда покажет на экране, оно приоритетнее)
   - Если у регистратора уже есть запись `A`/`CNAME` с таким именем, её нужно заменить.
4. Вернуться в Тильду и нажать «Проверить». Обновление DNS занимает от 10 минут до нескольких часов. SSL-сертификат (https) Тильда выпускает сама после проверки, это тоже занимает до часа. Основной сайт эти записи не затрагивают.
5. **Настройки сайта → Главная страница**: после создания страницы лендинга (шаг 2) выбрать её как главную, чтобы лендинг открывался по `https://general.cleanhub24.ru/`, а не по длинному адресу.

---

## 2. Создать страницу лендинга

1. «Страницы» → «+ Новая страница» → **«Пустая страница»**.
2. **Настройки страницы → Адрес страницы**: `generalnaya-uborka` (для второго `uborka-posle-remonta`).
3. **SEO** (заголовок и описание):
   - Генеральная.
     - Заголовок: `Генеральная уборка квартиры в Москве и Санкт-Петербурге: от 8 990 ₽ | CleanHub`
     - Описание: `Цена фиксируется заранее, предоплата 10%, остальное после приёмки. Привозим химию и пылесос. Выезд в день обращения. Рассчитайте стоимость за 1 минуту.`
   - После ремонта.
     - Заголовок: `Уборка после ремонта в Москве и Санкт-Петербурге: от 11 990 ₽ | CleanHub`
     - Описание: `Уберём строительную пыль и следы ремонта за один выезд. Цена фиксируется до начала работ, предоплата 10%, остальное после приёмки.`
4. **SEO → «Запретить индексацию страницы»**: включить (рекламные страницы не должны конкурировать с основным сайтом).
5. Меню, шапку, подвал и любые другие блоки Тильды **не добавлять**.
6. Добавить блок **T123 «HTML»** (категория «Другое»). Нажать «Контент», вставить **весь код из файла целиком** (с первой строки `<!-- … -->` до последнего `</script>`). Ничего не вырезать и не править. Проверить, что блок T123 не стоит в режиме «Скрыть на мобильных».
7. Сохранить. Опубликовать.

---

## 3. Попап с формой заявки (обязательно)

Лендинг открывает окно заявки по хуку `#popup:order`. Без него кнопки «Оставить заявку» ничего не откроют (пользователь увидит только быстрые каналы: WhatsApp, Telegram, звонок).

1. На ту же страницу добавить блок «Попап с формой» (например, из раздела «Форма и попап», любой с формой внутри).
2. В настройках попапа: **якорь/хук** `#popup:order`.
3. Поля формы (названия **буква в букву**, иначе заявка потеряет расчёт или CRM не разберёт поля):

| Поле | Тип | Обязательное | Заметка |
|---|---|---|---|
| Имя | текст | нет | |
| Телефон | телефон (с маской) | **да** | |
| **Расчёт** | **скрытое поле** | нет | сюда лендинг записывает весь расчёт клиента (площадь, тариф, доп. услуги) |
| **Сумма** | **скрытое поле** | нет | итоговая цена числом |
| Почта | email | нет | если на основном сайте есть |
| Комментарий | текст | нет | |
| utm_source, utm_medium, utm_campaign, utm_content, utm_term, yclid | скрытые поля | нет | для сквозной аналитики; Тильда сама подставляет значения из ссылки |

   Если нужен тот же набор полей, что в форме на основном сайте, проще всего **скопировать форму оттуда** (в списке блоков «Копировать в другой проект») и добавить два скрытых поля «Расчёт» и «Сумма».
4. **Согласия**: те же галочки/ссылки, что на основном сайте (политика обработки персональных данных, согласие на обработку, при необходимости согласие на рекламу). Ссылки ведут на cleanhub24.ru.
5. Кнопка формы: «Получить расчёт» или «Отправить заявку».
6. **После отправки**: переход на `https://general.cleanhub24.ru/spasibo` (во втором проекте `https://remont.cleanhub24.ru/spasibo`).
7. Скрытые поля работают так: лендинг сам находит поля «Расчёт» и «Сумма» в форме попапа и записывает в них значения в момент нажатия «Оставить заявку». Дополнительного кода не нужно.

## 4. Страница «Спасибо»

В каждом проекте:

1. «+ Новая страница» → «Пустая страница», адрес `spasibo`.
2. Добавить блок T123, вставить код из `spasibo.html`.
3. **Запретить индексацию**.
4. Именно посещение этой страницы считается «отправленной заявкой» в Метрике.

---

## 5. Заявки в CRM (то же, что на основном сайте)

Так как поддомен это отдельный проект, настройки уровня проекта надо повторить.

1. Открыть проект основного сайта → «Настройки сайта → Формы» и посмотреть, какие интеграции подключены (CRM, почта, Telegram и т. д.).
2. В каждом новом проекте подключить **те же** интеграции: «Настройки сайта → Формы → [сервис]».
3. В настройках формы в попапе («Куда отправлять данные») **отметить** эти сервисы.
4. Проверить на тестовой заявке: она появилась в «Заявках» Тильды, затем в CRM (с полями «Расчёт», «Сумма» и UTM-метками).
5. Отдельно уточнить у менеджера CRM, в какое поле сделки ложится «Расчёт» (если нужно, смапить на комментарий сделки).

## 6. Аналитика

В **каждом** проекте (Настройки сайта → Аналитика / Ещё):

1. **Яндекс.Метрика**: тот же счётчик `108429981` (тот же идентификатор, что в основном проекте). В Метрике → Настройки счётчика → «Дополнительные адреса» добавить `general.cleanhub24.ru` и `remont.cleanhub24.ru`. Включить Вебвизор, если включён на основном сайте.
2. **Цели Метрики** (тип «JavaScript-событие»), по одному набору на лендинг:

| Идентификатор (генеральная / после ремонта) | Что значит |
|---|---|
| `gen_calc_start` / `rem_calc_start` | начал пользоваться калькулятором |
| `gen_lead_click` / `rem_lead_click` | нажал «Оставить заявку» |
| `gen_call_click` / `rem_call_click` | нажал на телефон |
| `gen_wa_click` / `rem_wa_click`, `gen_tg_click` / `rem_tg_click` | написал в мессенджер |

   Главная цель: **«Посещение страницы» → URL содержит `/spasibo`**. Именно её выбирать целью оптимизации в Яндекс Директе.
3. **Коллтрекинг i-media** (проект `16499`): скопировать фрагмент из «Настройки сайта → Ещё → HTML-код для вставки в HEAD» основного проекта в новые проекты. Также попросить i-media **добавить оба поддомена** в проект, иначе подмена номеров не включится.
4. **Счётчик VK `3764497`** и скрипты рекламных сетей: скопировать аналогично, если нужны на этих страницах.
5. Номер телефона в лендингах стоит в тексте и ссылках `tel:`, коллтрекинг подменит его сам.

## 7. Что можно править без разработчика

В конце файла лендинга (в блоке T123) есть объект `window.CHL_CONFIG`. Здесь можно поменять без пересборки:

| Параметр | Что это |
|---|---|
| `metrikaId` | номер счётчика Метрики (сейчас `108429981`) |
| `popupHook` | хук попапа (сейчас `#popup:order`) |
| `wa` | номер WhatsApp в международном формате без плюса (сейчас `79152606655`) |
| `tg` | логин Telegram без `@` (сейчас `cleanhubru`) |
| `firstOrder` | скидка на первую уборку (выключена: `null`) |
| `tariffs`, `service` | цены, тарифы и доп. услуги калькулятора |

Тексты, структура и стили правятся только в исходниках (репозиторий, `landings/build.py`), после чего файлы пересобираются командой `python3 landings/build.py`. Для разовых правок текста можно менять код прямо в блоке T123.

## 8. Проверка перед запуском рекламы (10–15 минут)

Откройте лендинг по ссылке с метками:

```
https://general.cleanhub24.ru/?utm_source=yandex&utm_medium=cpc&utm_campaign=test&utm_content=1&utm_term=test
```

Чек-лист:

1. Страница открывается по https, без предупреждений. Шрифты корректные (UA-brand для заголовков, GothamPro для текста), логотип и фото на месте.
2. **Телефон** (390 px): первый экран с кнопкой виден без прокрутки, панель «Позвонить / Рассчитать» липнет снизу, галерея «до/после» листается.
3. **Калькулятор**: площадь вводится вручную, по умолчанию выбран «Премиум» с пометкой «Хит продаж», цена пересчитывается при смене тарифа и услуг.
4. «Оставить заявку» открывает попап. Отправить тестовую заявку (имя «Тест», свой номер).
5. После отправки открывается `/spasibo`.
6. В «Заявках» Тильды: поля «Расчёт», «Сумма» и UTM заполнены.
7. Заявка дошла в CRM (и уведомление на почту/Telegram).
8. В Метрике: сработали цели (`…_calc_start`, `…_lead_click`) и посещение `/spasibo`; визит виден в Вебвизоре.
9. Звонок с рекламной ссылки: номер подменился (коллтрекинг) и звонок виден в i-media.
10. Основной сайт cleanhub24.ru работает как раньше.

## 9. Что может пойти не так

| Симптом | Причина | Что делать |
|---|---|---|
| Нет https / «сайт не защищён» | сертификат ещё не выпущен | подождать до часа после проверки DNS |
| Поддомен открывает чужую страницу | не выбрана главная страница проекта | Настройки сайта → Главная страница |
| Кнопка «Оставить заявку» не открывает форму | нет попапа или другой хук | добавить попап, хук `#popup:order` |
| В заявке нет расчёта | названия скрытых полей не совпадают | поля «Расчёт» и «Сумма» (с заглавной буквой, кириллицей) |
| Нет целей в Метрике | поддомен не добавлен в счётчик | «Дополнительные адреса» в настройках счётчика |
| Не подменяется номер | поддомен не добавлен в i-media | написать в поддержку i-media |
| Шрифты «поехали» | не загрузились шрифты с CDN Тильды | проверить, что страница открывается из проекта Тильды, а не из файла; перезагрузить |
| Фото не грузятся | CDN jsDelivr или Тильды временно недоступен | обновить страницу, проверить доступ без VPN |
