# Личный кабинет CleanHub24: подключение

## Вставка в Тильду
1. В Тильде добавьте блок **T123 — HTML-код** на страницу `/lk` (или любую другую).
2. Вставьте в него содержимое `lk/cleanhub-lk.html` целиком.
3. Опубликуйте страницу. В демо-режиме (`mode: 'demo'`) кабинет работает на тестовых данных, код из SMS: `1234`.

Настройки лежат в начале скрипта (объект `C`). Их можно переопределить до блока:
`<script>window.CHLK_CONFIG={mode:'live',apiBase:'https://api.cleanhub24.ru/lk',telegramBot:'ваш_бот'}</script>`

## Что нужно для боевого режима
Тильда отдаёт только статичные страницы, поэтому регистрацию, SMS, Тейку и Telegram нельзя делать из браузера: ключи были бы видны всем. Нужен небольшой бэкенд (`apiBase`), который:

| Метод и путь | Что делает |
|---|---|
| `POST /auth/code` `{phone, purpose}` | Отправляет SMS-код (через SMS-провайдера). |
| `POST /auth/verify` `{phone, code, profile}` | Проверяет код, создаёт клиента при `purpose=register`, возвращает `{token}`. Для нового клиента создаёт карту в Тейке и начисляет приветственные бонусы. |
| `GET /me` | `{user, loyalty}`. `loyalty` берётся из Тейки: `card`, `balance`, `spent`, `levels[]`, `expiring`, `history[]`, `maxPay`, `referral`. |
| `PATCH /me` | Имя, email, дата рождения, адреса, настройки уведомлений. |
| `GET /orders` | `{orders:[{id,date,status,title,items[],total,bonusSpent,bonusEarned,address,slot}]}`. Статусы: `new`, `work`, `done`, `cancel`. |
| `POST /loyalty/promo` `{code}` | Применяет промокод. |
| `POST /telegram/link` | Возвращает `{url:'https://t.me/<бот>?start=<одноразовый токен>', token}`. |
| `GET /telegram/status?token=` | `{connected, username}`. Бот получает `/start <токен>` и привязывает `chat_id` к клиенту. |
| `DELETE /telegram` | Отвязывает Telegram. |
| `POST /auth/telegram/start`, `GET /auth/telegram/status?token=` | Вход через бота по тому же принципу: `{done, token}`. |

Все запросы после входа идут с заголовком `Authorization: Bearer <token>`.

## Источники данных
- **Бонусы и уровни**: API Тейки. Точные методы и формат сверьте с её документацией. Ключ Тейки хранится только на вашем сервере.
- **История заказов**: сайт на Тильде сам заказы не хранит. Заявки из форм Тильды нужно передавать вебхуком в вашу CRM или базу, а `/orders` отдавать оттуда, сопоставляя по телефону.
- **Telegram**: нужен бот через @BotFather. Бот шлёт статусы заказов, а при подтверждении заказа сервер начисляет бонусы в Тейке.

## Юридически
Форма регистрации содержит чекбокс согласия на обработку персональных данных. Укажите реальный адрес политики в `privacyUrl`.

## Фирменный стиль
Цвета и радиусы взяты с cleanhub24.ru (те же токены, что в калькуляторе): зелёный `#00B14F`, hover `#009C45`, тёмно-зелёный `#0B2517`, фон блоков `#F4F7F5`, линии `#DCE5DF`, радиус карточек 24px, кнопки-пилюли 30px. Шрифты подхватываются из Тильды через `--t-text-font` (Gotham Pro) и `--t-headline-font` (UA-BRAN), поэтому в блоке свои шрифты не подключаются. Для текстовых ссылок на белом использован более тёмный зелёный `#007A38`, чтобы хватало контраста.
