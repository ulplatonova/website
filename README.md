# CleanHub — рекламные лендинги для Тильды

Два отдельных конверсионных лендинга под платный трафик (Яндекс Директ и др.), собранные на основе cleanhub24.ru. Цены, тарифы, гарантии, отзывы и реквизиты взяты с вашего сайта (`/general`, `/afterepair`, `/price`, `/reviews`, `/garantiyi`).

| Лендинг | Файл для Тильды | Рекомендуемый адрес |
|---|---|---|
| Генеральная уборка | [`tilda/generalnaya-uborka.html`](tilda/generalnaya-uborka.html) | `/generalnaya-uborka` |
| Уборка после ремонта | [`tilda/uborka-posle-remonta.html`](tilda/uborka-posle-remonta.html) | `/uborka-posle-remonta` |
| Страница «Спасибо» (общая) | [`tilda/spasibo.html`](tilda/spasibo.html) | `/spasibo` |

Каждый лендинг — это **один блок T123 (HTML)** на пустой странице Тильды. Меню и ссылок на основной сайт в шапке нет: трафик не утекает. Страницы лежат на вашем домене как обычные страницы проекта.

## Воронка на каждом лендинге

1. **Оффер в первом экране** (H1 под запрос, цена «от», 4 довода, кнопка «Рассчитать за 1 минуту» и звонок) → 2. **Цифры доверия** (110 000+ уборок, 10+ лет, 5,0 по 157 оценкам) → 3. **Узнаваемые боли** → 4. **Калькулятор** (площадь → тариф → доп. услуги, цена пересчитывается сразу, цены из вашего прайса) → 5. **Что входит** + **до/после** (реальные фото) → 6. **Тарифы и таблица цен** → 7. **Как проходит работа** → 8. **Гарантии** (фикс. цена, оплата после приёмки, возврат денег) → 9. **Техника, команда, отзывы** → 10. **Акции** → 11. **FAQ** (снимает возражения) → 12. **Финальный CTA** (заявка / WhatsApp / Telegram / звонок).

Заявка идёт через ваш попап Тильды: **расчёт клиента (площадь, тариф, доп. услуги, итог) автоматически попадает в скрытое поле формы**, менеджер видит его в заявке. Параллельно есть «тихие» каналы для тех, кто не хочет оставлять номер: WhatsApp (с готовым текстом расчёта), Telegram, звонок. На телефоне внизу липкая панель «Позвонить / Рассчитать → Заказать».

## Подключение к Тильде (≈20 минут на лендинг)

### Шаг 1. Создайте страницу
Страницы → «+ Новая страница» → **пустая страница**. В «Настройки страницы»:
- **Адрес страницы**: из таблицы выше.
- **SEO → Заголовок / Описание** (рекомендую):
  - Генеральная: `Генеральная уборка квартиры в Москве — от 8 990 ₽ | CleanHub` / `Фиксированная цена в договоре, оплата после приёмки. Своя техника Kärcher. Выезд в день обращения. Рассчитайте стоимость за 1 минуту.`
  - После ремонта: `Уборка после ремонта в Москве — от 11 990 ₽ | CleanHub` / `Уберём строительную пыль и следы ремонта за один выезд. Цена фиксируется до начала работ, оплата после приёмки.`
- **Запретите индексацию** страницы (SEO → «Запретить индексацию»): рекламные страницы не должны конкурировать с основным сайтом.
- Меню, шапку и подвал Тильды **не добавляйте** — всё уже внутри блока.

### Шаг 2. Вставьте лендинг
Добавьте блок **T123 — HTML** (категория «Другое»), откройте «Контент» и вставьте **весь** код из файла. Опубликуйте.

### Шаг 3. Добавьте попап с формой (обязательно, иначе кнопки «Оставить заявку» не откроют форму)
На ту же страницу добавьте блок «Попап с формой» (T390 или любой попап с формой). Настройте:
- **Якорь/хук попапа:** `#popup:order` (как у вашего калькулятора `#popup:calc`).
- **Поля формы:** Имя, **Телефон** (обязательное, с маской) и **два скрытых поля**: переменная **`Расчёт`** (сюда придёт весь расчёт) и **`Сумма`** (итог). Названия должны совпадать буква в букву.
- **Согласия** — как в форме на cleanhub24.ru (политика + оферта).
- **После отправки:** переход на страницу `/spasibo`.
- **Получатели заявки** — те же, что на основном сайте (почта / CRM / Telegram).

Если попапа на странице нет, кнопки прокрутят к блоку контактов (WhatsApp / Telegram / звонок) — страница не «умрёт», но заявок через форму не будет.

### Шаг 4. Страница «Спасибо»
Создайте пустую страницу с адресом `/spasibo`, добавьте блок T123, вставьте `tilda/spasibo.html`, **запретите индексацию**.

### Шаг 5. Яндекс.Метрика (счётчик `108429981` уже подключён в ваших настройках проекта)
Создайте цели → тип «JavaScript-событие»:

| Идентификатор (генеральная / ремонт) | Что значит |
|---|---|
| `gen_calc_start` / `rem_calc_start` | начал пользоваться калькулятором |
| `gen_lead_click` / `rem_lead_click` | нажал «Оставить заявку» (открыл форму) |
| `gen_call_click` / `rem_call_click` | нажал на телефон |
| `gen_wa_click` / `rem_wa_click`, `gen_tg_click` / `rem_tg_click` | написал в мессенджер |

И главную цель: **«Посещение страницы» → URL содержит `/spasibo`** — это отправленная заявка. Именно её ставьте целью оптимизации в Директе. Для звонков с рекламы по возможности подключите коллтрекинг: на основном сайте в коде есть пиксель сервиса i-media (похоже на коллтрекинг), проверьте, работает ли подмена номера на новых страницах — в лендингах номер вынесен в ссылки `tel:` и текст, его легко подменить.

### Шаг 6. UTM-метки
Тильда сама сохраняет UTM из ссылки вместе с заявкой. Шаблон для Директа:
```
https://cleanhub24.ru/generalnaya-uborka?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}
```

## Что можно править без пересборки
В конце HTML-файла есть блок `window.CHL_CONFIG` — прямо в Тильде можно поменять: ID Метрики, номер WhatsApp и логин Telegram, **скидку на первую уборку** (`firstOrder`: `null` — выключить, тексты про скидку скроются сами), цены и доп. услуги калькулятора.

Для крупных правок (тексты, секции, стили) правьте `landings/build.py`, `landings/src/base.css`, `landings/src/app.js` и запустите:
```bash
python3 landings/build.py
```
Готовые файлы обновятся в `tilda/`. Предпросмотр в браузере (с тестовым попапом) — `landings/preview/`.

## ⚠️ Подтвердите перед запуском рекламы

1. **Скидка 10% на первую уборку (до 6 000 ₽).** На главной сайта она есть («Скидка 10% на первую уборку»), а в вашем калькуляторе на `/general` отключена (`firstOrder: null`). В лендингах она **включена** и автоматически уменьшает цену в расчёте. Если акции нет, выключите: `firstOrder: null` в `CHL_CONFIG` обоих файлов.
2. **Цена после ремонта.** В шапке `/afterepair` и в калькуляторе — «от 11 990 ₽», а в FAQ — «от 10 800 ₽». Я использовал 11 990 ₽ (как в калькуляторе). Там же срок: «5–7 часов» в шапке и «6–10 часов» в FAQ; в лендинге указано «обычно 5–7 часов».
3. **Telegram:** на сайте два аккаунта (`cleanhub_ru` и `cleanhubru`). Взят `cleanhubru`; если основной другой, поменяйте `tg` в `CHL_CONFIG`.
4. **WhatsApp:** на сайте `wa.me/89152606655`, в лендинге международный формат `79152606655` (тот же номер).
5. **Отзывы и имена** взяты дословно (с сокращениями и «…») со страницы `/reviews`; выбраны лучшие под тему каждой страницы. Фото «до/после» и команды — с вашего сайта; лучше со временем заменить на свежие кейсы именно под рекламные запросы (особенно «после ремонта»).
6. **Цифры «40+ пунктов чек-листа», «до 30 км от МКАД», «ответим за 5 минут»** взяты с вашего сайта; убедитесь, что они актуальны для рекламного режима.

## Советы по рекламе

- **Две отдельные кампании** (по странице), в каждой группы по намерению: `генеральная уборка квартиры / заказать / цена / москва` → лендинг генеральной; `уборка после ремонта / клининг после ремонта / уборка новостройки` → лендинг ремонта. Заголовок объявления = H1 лендинга (так выше релевантность и Quality Score).
- В тексты объявлений: «от 8 990 ₽», «цена фиксируется в договоре», «оплата после приёмки», «выезд сегодня».
- Минус-слова: `своими руками`, `инструкция`, `вакансии`, `работа`, `обучение`, `курсы`, `как сделать`, `фото`, `бесплатно`, `аренда`, `купить`.
- Сначала запустите на **Поиск** по горячим запросам; РСЯ — после сбора данных по конверсии. Оптимизация — на цель «заявка (`/spasibo`)».
- Через 1–2 недели: смотрите по Вебвизору, где отваливаются (калькулятор / форма), и A/B-тестируйте H1 и первую кнопку.
